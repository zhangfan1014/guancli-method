02

为什么是 cli，而不是其他

今年公司鼓励 AI 产品推荐与打单，AI 产品矩阵分为五类。站在客户成功视角，我做了一次个人客观取舍。

① 仪表板洞察 + 洞察 Agent
仪表板报告解读
本质是把数据喂给大模型+提示词固化分析思路，小客户付费转化难，中大客户可以尝试但25年已推过一波，短期再推转化难。​
再成交难
长尾小客户价格门槛过高。
② chatBI
智能问数
本质还是NL2sql，无法解决百分百准确的问题，交付过程重时间久但效果很难好，且与①同源，多数客户25年已被推荐过。​​
再成交难
再次成交机会相对小。
③ guancli
Agent 交互入口
AI 入口第一步，最顺手切进客户 AI 应用，因为现在AIAgent盛行。​
突破口
④ SuperApp
自定义网站搭建
只要能拿到数据（api或cli都可以），借助 WorkBuddy 等通用 Agent 搭站部署并不复杂。​
优势不明显
⑤ DecideX
数据治理 + 业务 Agent 搭建
客户侧落地成本高，且产品单价比较高，运营成本也高，不适合作为第一刀切入。​
相对较重
核心判断：cli 是 AI 入口的第一步。 跟客户整体聊下来会发现——在 AI 盛行的当下，客户侧基本都在拥抱 AI，或深或浅（不管是国外的 Codex 还是国内的 WorkBuddy）。客户使用 Agent 的习惯在逐渐养成，绝大多数客户希望在同一入口处理相关工作。站在 BI 厂商角度，用 guancli 是最好切入客户 AI 应用的点。所以选择用 cli 做有限的单点破局，再在此基础上深入沟通、摸排其他机会。

04

客户分成四种类型

培育过程里，我把客户按"感知度 × 使用深度"切成四档，分别对应不同的孵化动作。

4.1 最该主动孵化
LEVEL 1

无感知

完全没进群、对 cli 没感知。

→ 用「探意」案例展开讲
4.2 手把手带
LEVEL 2

浅使用

进群了，但不会用。

→ 首次安装 / 首次使用，先"能跑起来"
4.3 场景引导
LEVEL 3

中等使用

进群了，但用得不深。

→ 案例分享 + 更新通知，把单点扩成习惯
4.4 标杆运营
LEVEL 4

深度使用

进群且用得很好。

→ 沉淀案例、转介绍与二次机会摸排
05

打单案例：探X智能​​

以客户 A（「探X智能」）为例，演示 4.1 档客户的完整孵化链路。​

STEP 1 · 现场发现

客户对 cli 无感知，但存在明确切入点

现场沟通时发现客户对 cli 完全没概念，但同时具备两类特征：画像 3.3 用过 Public API ＋ 画像 3.1 想提效不知怎么用。价值已被他们自己验证过，只是没接上 guancli 这条更顺的路。

STEP 2 · 拉专项群定向孵化

把"会用"拆成五件小事，逐一陪跑

建立专项群做定向孵化，节奏是：首次安装 → 首次使用 → 案例分享 → 更新通知 → 产品答疑。不一次性灌输，而是让客户在每个小节点都拿到正反馈。

STEP 3 · 提前铺垫收费

在价值被感知后，再谈商业化

趁客户已经用顺手、离不开之前，提前铺垫"后期会进行收费"，把预期管理做在前面，避免后面临门一脚时心理落差过大。

06

过程中可能遇到的问题

真实打单里绕不开的几类阻力，以及我目前的解法。

⚠️买断客户怎么推？
  1. 6.1大版本升级优势：用新版能力点作为买断客户增购/升级的理由。
  2. 6.2cli 使用打信息差：客户不知道 cli 是否有版本限制，打的就是一个信息差。（慎用）
  3. 6.3告知 cli 存在缺陷：关于高级查询功能等。
⚠️竞品都没收费，为什么你们要收费？
  1. ①定位不一样：竞品目前的 cli 更多只是一个 API 接口封装（即取数），而我们提供的是一整套解决方案——现场直接给客户看一张产品能力图（右侧）：工具套件、资产查询、数据接入与管理、看板生成、数据加工、表单与任务、使用管控，七大模块一目了然。
  2. ②顺势植入行业地位：在对比中适当穿插着说——观远的 cli 是走在行业前列的。不硬吹，让产品能力图自己说话。
  3. ③让客户自己去调研：市面上主流的 CLI 产品都是超出额度进行收费的——以飞书、钉钉为例，还有企查查、天眼查等等，都很常见、很好查证。让客户自己得出"收费是行业惯例"的结论，比你说服一百遍都管用。
⚠️报价策略应该怎么设计？
  1. →有对比才有选择：给出阶梯 / 对照方案，让客户在"选什么"而不是"买不买"上做决策。
  2. →产品更新承诺：把路线图和迭代节奏讲明白，让报价买到的是"持续变强的能力"。
  3. →强调售后指导：把"买产品 = 买陪跑"说透，这是竞品免费方案难补的缺口。
07

其他值得补充的

站在方法论之外，几点一线体感。

🔑

cli 是入口，不是终点

单点破局后，再回过头摸排洞察 Agent / ChatBI / SuperApp / DecideX 的二次机会——cli 拿到的是信任和入口位。

🔁

孵化是持续动作，不是一次性

安装、使用、案例、更新、答疑，这五件事要循环做。客户的 Agent 习惯是养出来的，不是讲出来的。

🧱

坦诚比完美更有转化力

主动讲清 cli 的能力边界和使用方法，建立专业信任，也为后续收费铺垫了合理预期。​

📈

先把渗透率做厚，再谈规模

当前 50%+ 仍有上升空间，下一步是把"四类客户"的孵化 SOP 标准化，让复制不依赖个人手感。

一句话方法论

选对入口（cli）→ 找准画像（四类人）→ 分层培育（四档客户）→ 提前铺垫（价值后被收费）→ 单点破局后再摸排全产品机会。

它不性感，但一线跑得通。
